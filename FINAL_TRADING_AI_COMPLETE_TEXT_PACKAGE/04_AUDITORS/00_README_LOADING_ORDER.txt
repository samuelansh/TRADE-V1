# FINAL TRADING AI SKILL PACK

## Purpose
A modular companion pack for a Master Trading Agent Prompt.

## Loading principle
Do NOT treat every file as mandatory on every task.

Recommended order:
1. Master Prompt
2. Research Router
3. Load only the skills relevant to the current phase
4. Use Strategy Research Engine for discovery/development
5. Activate auditors for validation
6. Use Risk/Execution skills before any controlled forward execution
7. Record material experiments in the Research Ledger
8. Run Self-Evaluation before major decisions

## Core principle
More rules do not automatically produce better research. The agent should use the minimum sufficient methodology.

## Suggested phase map
- Discovery: Strategy Research + Research Director + Source Verification + Data Integrity
- Experimentation: Strategy Research + Backtest Auditor + Data Integrity
- Validation: Statistics + Overfitting + Red Team + Complexity
- ML: ML Auditor only when ML is actually used
- Execution: Risk + Execution only when relevant
- Final review: Self-Evaluation + Research Ledger
