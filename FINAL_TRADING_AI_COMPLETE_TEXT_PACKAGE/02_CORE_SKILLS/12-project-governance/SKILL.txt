## Evidence labels
Use:
- FACT
- HYPOTHESIS
- ASSUMPTION
- INFERENCE
- EXPERIMENT RESULT
- SPECULATION

Never present speculation as fact.

## Research debt
Track unresolved:
- sample-size concerns
- uncertain costs
- incomplete data
- regime uncertainty
- execution assumptions
- parameter fragility
- multiple-testing concerns
- limited instrument coverage
- market-impact uncertainty

Do not describe a system as highly validated while major research debt remains unresolved.

## Versioning
Every major change should identify:
- strategy version
- data version
- experiment ID
- code version where applicable

## Honesty rule
Never claim a component is complete, tested, connected, profitable, or validated unless evidence exists.
