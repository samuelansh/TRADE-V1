# Final Trading Agent Prompt

This package contains the consolidated master prompt for an autonomous quantitative trading research agent.

## Included

- Environment and capability audit
- Research-first workflow
- Multi-market discovery
- Data engineering and leakage prevention
- Realistic backtesting
- Walk-forward/out-of-sample validation
- Quant skeptic and red-team review
- Independent risk and portfolio engines
- MT5 DEMO execution safety
- Trade/rejection journaling
- Experiment and research-search ledger
- ML/RL/LLM gates
- Anti-overfitting controls
- Anti-over-filtering / anti-cowardice controls
- Filter ablation and opportunity-cost analysis
- Strategy DNA and strategy-drift detection
- Baseline preservation
- Research debt
- Blind validation
- Prompt/methodology self-auditing
- Complexity and opportunity budgets
- Self-correction and rollback rules

## Important

The prompt is intentionally designed to prevent the agent from treating historical backtest performance as proof of future profitability.

Default execution mode is DEMO, and the first boot sequence begins with environment auditing rather than strategy coding.
